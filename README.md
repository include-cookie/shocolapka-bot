# Neko Cookie bot

Telegram-бот адміністратор для чату "Програмісти і печеньки". Модерує учасників на вході, обробляє попередження/мут, пересилає приватні звернення адміністрації у форум-топіки та відповідає на них.

## Команди

### Приватний чат з ботом

| Команда | Опис |
|---|---|
| `/start` | Привітання |
| `/help` | Підказка як звернутись до адміністрації |

Будь-яке інше повідомлення в приватному чаті пересилається адміністрації окремим топіком у чаті адміністрації — так починається діалог з підтримкою.

### Груповий чат

| Команда | Хто може | Опис |
|---|---|---|
| `/rule` | будь-хто | Кнопка-посилання на правила спільноти |
| `/warn` | адміни, у відповідь на повідомлення | Видає попередження учаснику |
| `/mute [1d2h30m]` | адміни, у відповідь на повідомлення | Мутить учасника на вказаний час (за замовчуванням 5 хв) |

### Чат адміністрації

| Команда | Опис |
|---|---|
| `/help` | Список адмінських команд |
| `/start_dialog <chat_id>` | Розпочати діалог від імені бота з вказаним chat_id |

Відповідь у топіку діалогу пересилається користувачу, з яким цей діалог веде адміністрація.

### Автоматична модерація вступу

Коли новий учасник подає заявку на вступ до групи, бот у приватних повідомленнях:
1. Перевіряє, що заявник не бот (інтерактивне опитування)
2. Просить погодитись з правилами спільноти
3. Пропонує представитись
4. Схвалює заявку та вітає в чаті

## Права доступу бота

Бот має бути доданий адміністратором у **обидва** чати, вказані в конфігурації (`BOT_ADMIN_CHAT` — чат адміністрації, та групу спільноти), з такими правами:

### Група спільноти

| Право | Навіщо |
|---|---|
| Restrict members (`can_restrict_members`) | `/mute`, автомут — обмеження учасника (`restrictChatMember`) |
| Add new members / Invite users via link (`can_invite_users`) | Схвалення заявок на вступ (`approveChatJoinRequest`) у флоу модерації вступу |

Групу потрібно налаштувати з увімкненими заявками на вступ (Join Requests), інакше подія вступу до бота не дійде.

### Чат адміністрації

| Право | Навіщо |
|---|---|
| Manage Topics (`can_manage_topics`) | Створення топіків форуму для кожного діалогу (`createForumTopic`) |

Чат адміністрації має бути супергрупою з увімкненими темами (Topics/Форум).

### Загальне

У обох чатах бот бажано має бути повноцінним адміністратором (а не лише мати окремі права вище) — це також вимикає режим приватності (privacy mode) і дозволяє боту бачити всі повідомлення в чаті, що потрібно для `/warn`, `/mute` (реакція на reply) та пересилання повідомлень між учасником і адміністрацією. Якщо не робити бота адміном, привʼязку privacy mode потрібно вимкнути окремо через [@BotFather](https://t.me/BotFather) (Bot Settings → Group Privacy → Turn off).

## Розгортання

Конфігурація через змінні середовища — див. [`example.env`](example.env) для повного списку. Запуск через Docker Compose:

```bash
docker compose up -d          # локальна розробка (docker-compose.yaml)
docker compose -f docker-compose.prod.yaml up -d   # production
```

Міграції бази даних виконуються через Alembic (`pdm migrate`).
